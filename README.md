# 奶蛙 Codex 宠物

奶蛙（naiwa）是一只可在 Codex 中安装和使用的像素宠物，包含空闲、骑车、挥手、跳跃、失败、等待、工作和完成等动作。

![奶蛙动作预览](https://cdn.jsdelivr.net/gh/KaishenChiang/naiwa-codex-pet@main/preview.gif)

## 快速安装

Install this Petdex pet by running:

```bash
npx petdex@latest install naiwa-7
```

在 Codex 中运行以上命令即可安装奶蛙宠物。

Petdex 页面：[奶蛙 naiwa-7](https://petdex.dev/pets/naiwa-7#edit)
