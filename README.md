# 奶蛙 · naiwa

15 fps 动态版 Codex 宠物。

## 安装

下载 Release ZIP，解压后将其中的 `naiwa/` 文件夹复制到 Codex 宠物目录（通常是 `~/.codex/pets/`；Windows 为 `%USERPROFILE%\.codex\pets\`），然后重新加载 Codex。

目录应保持为：

```text
naiwa/
├── pet.json
└── spritesheet.webp
```
